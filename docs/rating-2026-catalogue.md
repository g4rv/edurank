## ⚠️ Resolved questions (reviewed with user 2026-07-02)

1. **RESOLVED — meaning of «Дані внесені» and who approves NPP items.** The column names the
   division whose own subsystem supplies that row (each division keeps its own data, like their
   current `Дані *.xlsx` files) — that division enters the value directly and it counts immediately.
   **Blank rows = NPP self-report: submitted from the profile and AUTO-APPROVED — no verification
   queue, nobody reviews them before they count.** Corrections happen after the fact (post-moderation):
   **ННВ editors or ADMIN** can discard a wrong entry with a reason (status `REMOVED`),
   and the NPP can resubmit.
   `verifyingDivisionId` is therefore set only on division-managed types (= who enters) and is
   `null` for NPP types.
2. **RESOLVED — `2.1` Виконання навчального навантаження.** The "1" in the «Критерії» column is the
   coefficient. The division enters the points number directly; score = entered value × 1.
3. **RESOLVED — numbering of the section 2 tail.** Follows the sheet: 2.8 = кураторство (відеолекції
   carries the same date-serial in the sheet — kept under 2.8), **2.9 = сайт + соцмережі (one group)**.
4. **RESOLVED — `2.9` соцмережі verifier.** Same group as сайт → **ННЦЗЯО enters both** (confirmed).
5. **RESOLVED — select-type items** (звання, посада, quartile, ролі…): `score = option points ×
coefficient`; coefficient = 1 for 2026. Admin can scale a whole item later by editing its
   coefficient; changing individual option points requires a code change (accepted).

## How to read the tables

- **Код** — stable internal `ActivityType.code` (semantic, survives yearly renumbering).
- **Тип** — `FIXED` (score = coefficient × count) · `SELECT` (score = points of chosen option) ·
  `MULT` (score = coefficient × value) · `CHECK_SUM` (сума позначених чекбоксів, розділ 5).
- **Вносить** — `НПП` = NPP submits from profile, **auto-approved** → `INPUT: NPP_SUBMISSION`;
  a division key = division enters via its own panel, counts immediately → `INPUT: DIVISION_MANAGED`.
- **Перевіряє** — `verifyingDivisionId`: for division-entered rows = the entering division;
  for NPP rows = `—` (null, no verification — see resolved #1).
